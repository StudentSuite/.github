# Contributing to StudentSuite

StudentSuite builds free, open tools for students. Each project lives in its own repository with its own contributing guide where it needs one: start there, since setup and checks differ per project.

- [StudyMap](https://github.com/StudentSuite/StudyMap): a map of student places and competitions.
- [awesome-student-resources](https://github.com/StudentSuite/awesome-student-resources), [awesome-study-resources](https://github.com/StudentSuite/awesome-study-resources), and [awesome-skills-plugins-for-students](https://github.com/StudentSuite/awesome-skills-plugins-for-students): curated lists.

## Everywhere

- Read the [Code of Conduct](CODE_OF_CONDUCT.md). It applies in every repository, issue, and pull request.
- Look for an existing issue before opening one, and say in the issue if you plan to work on it.
- Keep a pull request to one change, describe what changed and why, and link the issue it closes with one `Closes #N` per issue.
- Run the project's own checks before you push. A red check blocks merge.
- Write plain, direct copy. No em dashes.

## Security problems

Never report a vulnerability in a public issue. See [SECURITY.md](SECURITY.md).
