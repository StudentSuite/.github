# StudentSuite/.github

This repository holds two things for the [StudentSuite](https://github.com/StudentSuite) organization:

- `profile/README.md`, the page shown at [github.com/StudentSuite](https://github.com/StudentSuite).
- Default community health files. Any StudentSuite repository without its own copy uses these: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), [CONTRIBUTING.md](CONTRIBUTING.md), [SECURITY.md](SECURITY.md), the issue forms in [ISSUE_TEMPLATE/](ISSUE_TEMPLATE), and [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md).

A repository that keeps its own file (StudyMap and the awesome lists keep their own contributing guides and issue forms) uses that one instead. [LICENSE](LICENSE) covers this repository only; each project has its own.
